# Todo comienza cuando el empleado abre su navegador web, el cual actúa como el cliente. En la barra de direcciones escribe la URL de la aplicación, la cual apunta a una dirección IP específica (http://127.0.0.1:5000) y a un puerto de comunicación (como el 5000) donde está escuchando nuestro servidor.   Al presionar Enter, el navegador envía una petición inicial mediante el protocolo HTTP  solicitando la página principal. Esta solicitud llega al backend de nuestra aplicación, el cual está programado en Python utilizando el microframework Flask. Flask recibe la petición, identifica la ruta solicitada. y ejecuta la función asociada para buscar un template  y devolverlo al navegador.   El servidor envía de vuelta una respuesta HTTP que contiene el código del frontend, es decir, la parte visual con la que interactúa el usuario. Esta interfaz está estructurada con etiquetas HTML, estilizada con reglas CSS y apoyada en las clases y componentes de Bootstrap para que el diseño sea limpio, responsivo y cuente con una barra de navegación consistente (si se usan componentes interactivos de Bootstrap como menús desplegables, también interviene JavaScript en el navegador para darles dinamismo).   Una vez cargada la página, el empleado ingresa la cantidad y el precio en el formulario y hace clic en el botón de calcular. En ese momento, el navegador envía los datos al servidor mediante una nueva petición HTTP utilizando el método POST, el cual permite mandar la información del formulario de manera segura en el cuerpo del request.   Nuevamente en el backend, Flask captura esa petición POST en la ruta correspondiente. Mediante código en Python, extrae los valores enviados, realiza la operación matemática para calcular el importe de la compra e inyecta ese resultado dentro de un template de HTML. Finalmente, el servidor envía un último response con la página actualizada al cliente, permitiendo que el empleado visualice el total de la compra directamente en su pantalla.
